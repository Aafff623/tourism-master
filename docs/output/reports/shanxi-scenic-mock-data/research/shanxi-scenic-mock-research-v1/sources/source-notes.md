# 来源与核验说明

## 采用原则

1. 世界遗产名称、入选年份、核心价值优先使用 UNESCO World Heritage Centre。
2. 全国重点文物保护和保护原则优先使用国家文物局及地方政府公开资料。
3. A 级景区、票价、开放时间、预约、车辆与景交政策属于动态信息，开发时应再次查询文化和旅游主管部门、景区官网或官方公众号。
4. 搜索引擎摘要、旅游平台、百科和个人游记只能作为线索，不应作为上线时唯一来源。
5. 包内价格仅为宽区间，用于 UI 和 Mock，不是购买建议。

## 核心已核验事实

- UNESCO 使用 `Yungang Grottoes`，并记载 252 座洞窟和约 51,000 尊造像。
- UNESCO 使用 `Mount Wutai`，其遗产类型为文化景观，并强调佛教建筑与自然环境的关系。
- UNESCO 使用 `Ancient City of Ping Yao`，遗产组成包括古城、双林寺和镇国寺。

## 动态字段核验流程

建议 Agent 为以下字段增加：

```json
{
  "valueZh": "...",
  "valueEn": "...",
  "verificationStatus": "UNVERIFIED | VERIFIED",
  "verifiedAt": "YYYY-MM-DDTHH:mm:ss+08:00",
  "sourceUrl": "https://..."
}
```

开发或答辩演示前至少核验：

- 开放与停止入园时间
- 成人、优惠和外籍证件票务
- 是否实名预约
- 景交和私家车政策
- 临时关闭及天气风险
- 拍照、闪光灯、三脚架规则
- 无障碍路线与卫生间
- 游客中心和医疗点

## 图片合规

UNESCO gallery 与 Wikimedia Commons 只作为检索入口。下载具体文件后必须检查：

- 许可类型
- 是否允许修改
- 是否允许商业或公开展示
- 作者署名格式
- 是否要求相同方式共享

不要把搜索结果图片 URL 直接当作永久 CDN。
